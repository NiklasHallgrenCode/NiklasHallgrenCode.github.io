Data: league game list from the Steam Web API (league 19868), match details from OpenDota's parsed replays. A ward counts as dewarded when it disappeared before its full duration and an enemy hero got the kill.

Level 1 tab: hero positions (one per second), Smoke of Deceit uses and deaths are read directly from the match replays. A smoke counts as broken when a hero lost it before the full 45 seconds. Positions 1–5 are estimated from lanes and net worth.

Map: Dota 2's in-game minimap from the game files, with wards placed using the game's own minimap coordinates, so positions match the minimap you see in game. Dota 2 is a trademark of Valve Corporation; this page is not affiliated with Valve.
